# CPR Research System V2.2.7

## 緊急修正版：退回 V2.2.3 相機流程，只修介面與分析顯示

V2.2.7 以 V2.2.3 為基礎，保留原本可用的攝影機啟動與鏡頭清單流程。

本版不再修改前後鏡頭、自動 fallback 或 getUserMedia 複雜流程，避免再次造成攝影機抓不到。

## 本版修正

- 相機流程退回 V2.2.3
- 保留 10 秒準備倒數
- 新增鏡像 / 不鏡像顯示選項
- 新增骨架顯示 EMA 平滑
- CSV 仍保留原始 MediaPipe 座標，不使用平滑座標污染研究資料
- 自動分析手臂改為優先判斷鏡頭近側
- 畫面顯示目前分析手臂：左側 / 右側，以及選擇原因
- posture_metrics.csv 同時記錄左右手角度、visibility、z 值、側邊分數
- 移除畫面上「影像位移 px」判斷卡片，但資料仍持續記錄
- 手機版順序調整為：影片 → 即時判斷值 → 錄影按鈕 → 系統訊息 → 下載資料

## 現場測試建議

1. 先按重新整理攝影機清單。
2. 選擇要用的攝影機。
3. 按開啟攝影機與模型。
4. 確認攝影機正常顯示後再開始測試。
5. 若右手靠近鏡頭，畫面應顯示「分析手臂：右側｜鏡頭近側」或類似訊息。
