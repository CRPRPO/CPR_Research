# CPR Research System V2.2.5

本版延續 V2.2.0 的三模式架構，並修正現場測試回報的三個問題：

1. 確認系統使用 MediaPipe Pose Landmarker Full。
2. 強化髖部顯示：骨架畫面會明顯標出 LH / RH，並顯示肩髖連線與髖部連線。
3. 新增「開始測試後 10 秒準備倒數」；倒數期間不錄影、不記錄骨架資料，倒數結束後自動開始正式錄影。

## 檔案

```text
index.html
live.html
replay.html
analyze.html
style.css
live.js
README.md
```

## 主要設定

- 解析度：640×480
- FPS：30fps
- 模型：MediaPipe Pose Landmarker Full
- 錄音：false
- 錄影長度：30 秒 / 60 秒 / 120 秒
- 準備倒數：10 秒
- 輸出：
  - 原始影片 webm
  - landmarks.csv
  - posture_metrics.csv
  - metadata.json
  - 一鍵 ZIP

## 部署後確認

部署 GitHub Pages 後請按 Ctrl + F5，並確認 live.html 載入：

```text
live.js?v=20260821-v225
```

## 注意

若外接攝影機在畫面中抖動明顯，請檢查：

- 光線是否足夠
- 手腕、手肘、髖部是否完整入鏡
- 外接攝影機是否自動曝光造成動態模糊
- 受試者是否在倒數期間已經完成定位


## V2.2.5 更新重點

- 手機版將即時判斷卡片移到影片正下方，方便一邊看影片一邊看姿勢判斷。
- 桌機版也改為「設定區 + 影片/判斷區」兩欄，避免判斷區離畫面太遠。
- 開啟手機攝影機時若實際取得直向畫面，例如 480×640，系統會在訊息列提醒正式研究建議橫放手機後重新啟動攝影機。
- `getUserMedia()` 增加 4:3 aspectRatio ideal，但手機瀏覽器仍可能依裝置方向回傳直向影像；正式測試以 metadata 的 actual_width / actual_height 為準。


## V2.2.5 更新重點

- 修正電腦橫式版面：設定區、影片區、現場操作與即時狀態改成三欄，開始錄影按鈕與判斷值可在同一視窗中看到。
- 修正手機直式版面：手機直式錄影時，影片會維持直式比例，判斷值與操作按鈕放在影片下方，避免影片撐滿畫面。
- 修正影片容器比例：依實際攝影機解析度自動切換橫式或直式顯示，不再把 480×640 拉成接近正方形。
- 手機直式模式下優先要求 480×640 / 30fps；電腦與一般橫式仍以 640×480 / 30fps 為主。


## V2.2.5 修正

- 攝影機來源加入「自動選擇攝影機」，即使清單尚未讀取，也可直接啟動。
- getUserMedia 改成多層 fallback：指定攝影機 exact → 指定攝影機 ideal → 自動選擇 → 瀏覽器預設 → 最低限制。
- MediaPipe Full 模型載入加入 GPU 失敗後 CPU fallback。
- 攝影機清單在取得權限後重新整理，避免一開始只看到「尚未讀取攝影機」。
